Four hospitals train one heart-disease model. No patient record leaves any hospital.

Each hospital trains on its own patients and sends only model updates. Noise protects each patient, and the updates are masked so the server only ever sees their sum.

Federated learning
the model travels to the data; the data never travels.
Differential privacy (ε)
calibrated noise in training; a smaller ε means less can be learned about any one patient.
SecAgg+
secure aggregation: updates are masked so the server can add them up but not read any one.

Many finished runs (no attack), averaged over seeds; whiskers show ± one standard deviation. More noise means stronger privacy (smaller ε) and usually a little less accuracy.

Attacks

Two threats. A poisoning hospital sends a bad update to wreck the shared model. A curious server runs a membership test: given a patient, was this record used in training?
